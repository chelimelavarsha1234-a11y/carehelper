# CareCircle – Trusted Support for Independent Elderly Living
# 1. Introduction
  CareCircle is a digital platform designed to support elderly people who live independently, especially when their family members cannot be physically present. It connects elderly     people, their families, and verified care helpers through one trusted platform for everyday support.
CareCircle is not intended to replace family members, doctors, professional medical care, or emergency services. Instead, it provides an additional support layer for everyday needs.
# 2. Problem Statement
  Many elderly people living alone may need help with simple everyday activities such as purchasing groceries, attending appointments, getting digital assistance, transportation, household support, or companionship.
At the same time, their children or family members may live in another city or country and may not be able to provide physical support whenever needed.
The key question is:
What happens when an elderly person needs everyday help but cannot request it themselves?

## 3. Proposed Solution 
  CareCircle is a website that helps elderly people get everyday support when their family members cannot be nearby. It connects elderly people, family members, and verified helpers in one platform.
1. Four Modules
  •	Elderly: The elderly person can request help for groceries, appointments, transportation, companionship, etc.
  •	Family: Family members can request help for their elderly relatives and monitor their care remotely.
  •	Care Helper: Helpers can see requests, accept them, provide support, and update the care status.
  •	Admin: Admin verifies helpers, manages users, and handles complaints to maintain safety.
2. On-Demand Help
  If an elderly person needs help, they can create a request by selecting the type of help, date, time, location, and details.
  Example:
  Elderly needs grocery help → Request is created → Verified helper accepts → Helper provides support → Request is completed.
  Family members can also create requests on behalf of elderly people.
3. Dedicated Care
This is one of the main features of CareCircle.
If an elderly person cannot use the website or needs support for several hours, their family member can arrange a dedicated helper.
For example:
Daughter logs in → Selects her mother → Chooses 9 AM–6 PM → Selects required support → Selects a verified helper → Helper accepts → Provides support → Family receives updates.
This allows family members to support their elderly relatives even when they live far away.
4. Trust and Verification
To make the platform safer, helpers are verified by the admin before they can provide support.
The admin checks their basic details, skills, experience, and service area.
Only approved helpers can receive care requests.
5. Care Updates
CareCircle keeps the family informed about the support.
For example:
Helper checked in → Support provided → Care update added → Helper checked out → Care completed.
This helps the family know what is happening without being physically present.
6. Communication
CareCircle allows connected users to communicate.
Elderly ↔ Helper
Family ↔ Helper
For example, a family member can ask the helper about the elderly person's current support status.
7. CareCircle Assistant
The CareCircle Assistant helps users with care-related information.
For example:
•	Elderly: “Who is my helper today?”
•	Family: “What is my mother's care status?”
•	Helper: “I have arrived.”
It helps with care coordination, but it does not provide medical advice.
8. Safety
CareCircle can provide SOS, trusted contacts, and family notifications.
However, it is not an emergency medical service. For serious emergencies, users should contact the appropriate emergency or medical services.
CareCircle – Workflow
# 4. The CareCircle workflow :
  1.User Needs Help
  An elderly person needs everyday support, such as grocery help, an appointment, transportation, or companionship.
  2. Request is Created
  The elderly person or a family member creates a help request with the required service, date, time, and location.
  3. Helper Matching
  CareCircle finds verified helpers based on their service area, skills, and availability.
  4. Helper Accepts
  The suitable helper views the request and accepts it.
  5. Support is Provided
  The helper visits the elderly person and provides the requested assistance.
  6. Status Updates
  The helper checks in, updates the progress, adds a care note, and checks out after completing the task.
  7. Family is Updated
  The family can see the care status and communicate with the helper remotely.
  8. Request Completed
  After the support is finished, the request is marked Completed, and the care summary is available to the family.
